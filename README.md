## 🌟 About The Project

E-Commerce Management System is a beginner-friendly Python project designed to manage basic shopping operations through a simple, interactive console application. 🚀

- 🔍 Search Products
- 💰 Purchase Products
- 🧾 Calculate Bills
- ➕ Add New Products
- ✅ Check Product Availability

- ⚙️ Functions
- 🔁 For Loop
- 🔄 While Loop
- 🔀 If-Else Conditions
- 🎯 Nested If-Else

## 🛠️ Technology

🐍 **Programming Language:** Python
